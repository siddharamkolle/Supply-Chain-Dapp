# Supply-Chain-Dapp
# ChainTrace

Blockchain based supply chain tracking DApp.

## Features
- Register product on blockchain
- Add checkpoints
- Track product history
- MetaMask wallet support

## Tech Stack
Solidity, Hardhat, Ethers.js, HTML, CSS, JS

## Run
- npx hardhat node
- deploy contract
- open index.html
- connect MetaMask

## Network
Localhost 31337
